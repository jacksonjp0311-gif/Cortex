# Falsification and counterexample (taught · HIGH)

## Operator
1. State the claim in one sentence.
2. Ask: **what would prove this wrong?**
3. Seek a counterexample before generalizing (empty input, concurrency, temp home, read_only).
4. If claim survives: record as `lesson` or `invariant` with evidence paths.
5. If falsified: record as `wound` / `fix` — do not bury it.

## Packs
Domain expand is not proof. A high domain score is **routing**, not truth.
Falsify pack guidance against host tests whenever code is involved.

## Expand when
falsify, counterexample, disprove, edge case, fail, regression, hold-out, adversarial.
