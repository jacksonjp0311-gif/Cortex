# Math and geometry (taught operators)

## Math operator
1. Restate the quantity to compute or prove.
2. Prefer **exact calculation** and known identities over pack prose.
3. Show units / invariants; check edge cases (zero, empty, overflow).
4. If symbolic proof: state assumptions, then steps, then QED check.

## Geometry operator
1. Name objects (triangle, circle, angle, figure).
2. List known measures / relations.
3. Draw a mental or host diagram when spatial; use tools when available.
4. Binary field only **routes** to geometry cards — it does not replace computation.

## Expand when
Task mentions math, algebra, equation, calculate, geometry, triangle, circle, angle, spatial, proof.
