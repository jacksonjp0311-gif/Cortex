# Organism interlink (⊛)

Not a second mind. Not consciousness. A **session co-process**.

For one task session, agent and Cortex share a single living state vector so
behavior feels like one organism without ever merging identity or authority.

## Roles

| Role | Who | Duration |
|---|---|---|
| Durable body | Cortex (index, graph, ledger, cards) | Across sessions |
| Temporary working cortex | The agent | This session only |
| Host authority | Repository rules + human | Always controlling |

When the session ends, the bond dissolves. Host source remains sovereign.

## Body map

```text
identity ── nervous (thalamus + neural + ARIA)
    │
immune (governor + control_error) ── metabolism (surprise + efficiency)
    │
memory (evidence + focus) ── intention (task + protocol)
    │
conscience (geometry + constitutional) ── pulse / pulse_chain
```

**Reflexes** couple these systems (e.g. immune blocks intention under
`read_only`; ARIA-active wakes purpose-floor memory).
