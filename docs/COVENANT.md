# Cortex Covenant — Aligned Geometry

This document is the frozen moral and engineering constitution of Cortex.
Features argue *against* it only by explicit supersession in a later release;
they may not walk around it.

## The five axes (interlocks)

```text
                    AUTHORITY (never self-expand)
                           |
              CONTINUATION (GCMT planes)
                           |
     EVIDENCE -------- ACTIVATION -------- LANGUAGE
   (source>learned)   (known≠active)    (ARIA≠exec)
                           |
                    ECONOMICS (deferred / work-proxy)
```

| Axis | Law |
|---|---|
| **Authority** | Cortex never authorizes source mutation. Promotion is monotonic without a content-addressed external grant. |
| **Evidence** | Current source, tests, and runtime outrank Discovery Cards, association weights, and inference. |
| **Activation** | Known ≠ active ≠ searchable. Probes and side effects must not wake or materialize ARIA bulk. |
| **Language** | ARIA is native semantic substrate. It is never auto-executed and grants no capability. |
| **Economics** | Deferred bulk survives bootstrap and generic activation. Wake pays materialization once, visibly. |

## Non-goals (refused by default)

- Biological fidelity, consciousness, or AGI claims
- Second memory database or competing consolidation path
- Automatic ARIA plan execution
- Learned or fluent authority
- New “organs” that do not reduce tension on an existing axis

## Sacred practice (not idol)

Sacred means **consecrated constraint**, not untouchable myth:

- measure with `cortex mirror` and fluency corpora
- record breaks; fix lies in economics or authority
- keep `claim_boundary` on every supervisory surface

## Release gate

```bash
python -m cortex mirror --json   # require glow: true
python -m pytest tests -q
python -m cortex benchmark --verify --json
```

A glowing mirror is necessary. Foreign-host proof is required for geometry-aligned releases.

## Claim boundary

This covenant is a repository-local policy for Cortex development and operation.
It does not bind external law, confer rights, or prove universal safety.
