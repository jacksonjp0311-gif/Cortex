# Alpha.28 — Bounded Bridge-Low Relational Screen

Alpha.28 is a four-call development screen over the first alpha.27 panel. Its
purpose is task calibration, not competence transfer.

Before invocation Cortex freezes:

- the exact four `bridge_low` cases;
- public corpus hash and private contract commitment;
- relational evaluator identity and public relation ontology;
- runtime-selected provider/model identity and live adapter provenance;
- task-only context, zero tools, four-call ceiling, and stop window;
- all-false mutation, execution, memory-admission, and policy authority.

The frontend, caller, model, and provider cannot submit a score. Cortex reloads
the canonical preregistration, reconstructs every native trajectory, resolves
the private contract from the host vault, and recomputes the typed relational
verdict.

The screen disposition is:

```text
30%..70% success  -> informative development band
above 70%         -> ceiling; separately authorize bridge_mid
below 30%         -> floor; stop and audit before further calls
UNKNOWN           -> stop and repair response contract/transport
```

Even an informative band does not prove Cortex improvement. It only creates the
measurement conditions required for a later task-only versus sham versus
relevant semantic-context experiment.
