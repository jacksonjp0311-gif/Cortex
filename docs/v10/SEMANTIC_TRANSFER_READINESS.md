# Cortex v10.0.0-alpha.15 — Semantic Transfer Readiness Pulse

Alpha.15 is a lightweight experimental governor around the alpha.14 semantic
bridge. It inspects the canonical memory ledger before any paid or live model
call and asks whether Cortex possesses the evidence geometry needed for an
informative three-arm transfer pulse.

```text
canonical memories
       ↓
historical lineage verification
       ↓
modern semantic binding
       ↓
current epoch/lifecycle eligibility
       ↓
relevant + sham pair availability
       ↓
canonical non-ceiling target calibration
       ↓
allow at most six calls, or execute zero
```

Caller-supplied task-family names describe intent. They cannot prove that a
target corpus is calibrated. A readiness result may reduce the next call budget
to zero; it cannot expand policy, promote memory, or establish transfer.

## First pulse

The first pulse inspected the six admitted memories in the live Cortex ledger:

```text
canonical semantic ready     0
legacy partial               6
model calls executed         0
state                        SEMANTIC_TRANSFER_HELD
```

All six rows predate the modern candidate-material and cohort bindings required
to independently reconstruct their semantic content. They remain historical
records, but cannot be silently upgraded into alpha.14 cognitive guidance.
Several also bind to an earlier epoch or unresolved legacy lineage.

The result adapted the next-run policy to:

```text
action                 generate_modern_verified_source_experience
maximum live calls     0
automatic promotion    false
automatic expansion    false
```

That is not experimental failure. It is token conservation: Cortex discovered
that the treatment did not yet exist and declined to pay a model to measure it.

## Next admissible run

The next pulse remains blocked until Cortex has:

1. a modern canonical lesson derived from independently verified source
   experience;
2. a semantically distinct canonical sham lesson;
3. source/target separation so the lesson does not contain the held-out answer;
4. a canonical calibration showing baseline success in the declared
   `0.30–0.70` band; and
5. a frozen evaluator and maximum six-call budget.

Only then may Cortex execute:

```text
A = task only
B = verified irrelevant sham
C = verified relevant lesson

G_relevance = U_C - U_B
```

Readiness is not empirical benefit. A later successful relevant arm will still
require canonical outcomes, matched controls, discordance, and independent
evaluation before Cortex may describe a measured effect.
