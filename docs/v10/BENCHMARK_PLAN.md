# Native Runtime Benchmark Plan

Alpha 1 promotion measures mechanism correctness before autonomy claims.

## Correctness panel

- one complete context/model/tool/result/continuation/final trajectory;
- two replaceable scripted adapters through one core contract;
- strict event ordering and hash-chain reconstruction;
- denied tool and path traversal rejection;
- malformed/replayed provider response rejection;
- hidden/provider-native material exclusion;
- legacy v9 test compatibility.

## Operational panel

Future empirical commissioning should record per-turn latency, tool latency,
tokens, cost, event count, context size, output bytes, interruption latency,
and reconstruction time. Samples must identify provider evidence class and
must not convert fixture success into empirical agent competence.

## Held claims

Alpha 1 does not measure autonomous coding quality, long-horizon reliability,
cross-provider parity, safe arbitrary command execution, or UI usability.
