# Cortex v10.0.0-alpha.17 — Sham-Controlled Semantic Calibration

Alpha.17 prepares the first experiment capable of separating useful semantic
knowledge from extra prompt volume. It performs no live or paid inference.

## Experimental geometry

The eventual three arms remain:

\[
A=\text{task only},\qquad
B=\text{verified irrelevant sham},\qquad
C=\text{verified relevant lesson}.
\]

The quantities of interest are:

\[
G_{context}=U_B-U_A,
\qquad
G_{relevance}=U_C-U_B,
\qquad
G_{total}=U_C-U_A.
\]

`G_relevance` is the important contrast. It isolates the relevant lesson from
formatting, Cortex identity, and additional tokens.

## Verified lesson pair

The commissioning store now contains two modern structural experiences:

- relevant: invalidate persistent cached state before trusting a reread after
  mutation;
- sham: normalize line endings before hashing portable text fixtures.

Each independently traverses canonical circulation, competence distillation,
semantic witnessing, and epistemic-event admission. Their competence and
witness identities are distinct.

Both remain `synthetic`. This proves the experiment mechanism, not that either
lesson transfers empirically.

## Answer-sealed calibration corpus

The development corpus contains one cache-coherence family, three difficulty
levels, and four variants per level. The committed artifact contains:

- public prompts;
- exact response contracts;
- case identities and secret-salted answer commitments;
- the private answer-key commitment.

It does not contain the answer key or the random commitment secret. This avoids
making four-option answers recoverable by brute force. Any prompt or key
modification breaks verification.

## Sequential call budget

The initial live screen is exactly four task-only calls at level two:

| Result | Disposition |
|---|---|
| 0/4 | move easier |
| 4/4 | move harder |
| 1–3/4 | candidate band; request separate authority for four confirmations |

Four cases are screening, not calibration. A task level becomes eligible only
after the existing information-calibration machinery receives enough
canonically reconstructed outcomes and places success inside the declared
30–70% band.

Caller success booleans are not accepted. A live executor must reconstruct
each outcome from the canonical model-circulation ledger.
