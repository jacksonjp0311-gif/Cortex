# Cortex v10.0.0-alpha.23 — Live Semantic Causal Screen v2

Alpha.23 performs the first fresh measurement using the evaluator frozen in
alpha.22.

## Bound path

```text
canonical alpha.22 evaluator preflight
  -> exact public corpus
  -> exact private v2 contract from OS vault
  -> host-registered live adapter
  -> four new task-only calls
  -> immutable native trajectories
  -> deterministic semantic evaluation
  -> reconstructed sequential screen
```

Changing the evaluator hash, private commitment, corpus, adapter identity, or
adapter provenance after preregistration fails closed. A fixture adapter cannot
open the live screen.

## Experimental boundary

The run is capped at four level-three calls. No tools, memory, sham lesson, or
relevant lesson are projected. The screen can locate a development difficulty
band; it cannot establish semantic transfer or Cortex improvement.

UNKNOWN remains distinct from FAIL. Malformed JSON or an invalid evaluator
holds the screen instead of being counted as task failure. All authority flags
remain false.
