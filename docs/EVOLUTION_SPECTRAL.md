## 1. The deeper correction (what to build)

### Old model (still useful for one mode)

```text
Λ_{t+1} = ρ · Λ_t + μ_t
```

One scalar retention ρ for the whole body — good for simple connect averages,
wrong as a *universal* memory law.

### Spectral model (high priority)

A common upstream *signal* (task pulse, connect pass, organism beat) is
broadcast. **Memory is not stored only in the broadcaster.** It is distributed
across **decoders** (memory kinds / graph resolutions / evidence lanes), each
with its own retention kernel:

```text
u(t)  →  {K_g}  →  {Λ_g}  →  {Ξ_g}  →  {m_g}
```

| Symbol | Meaning in theory | Meaning in Cortex |
|---|---|---|
| `u(t)` | Common forcing / pulse | Connect pass · task · Thalamus route · organism systole |
| `K_g(τ)` | Decoder memory kernel | Per-kind / per-lane / per-resolution retention |
| `Λ_g` | Filtered retained evidence | Working score / credit / coact strength for class *g* |
| `Ξ_g = Λ_g / h_g` | Consequence-normalized state | Bounded by Governor / immune / contract floors |
| `m_g` | Commitment / expression | Ranker use · packet inclusion · distill · (never host edit) |

Exact continuous form (motivation only):

```text
Λ_g(t) = ∫ K_g(τ) · ℓ(t−τ) dτ
K_g(τ) = β_g · e^{−δ_g τ}     (or sum of a few shared modes)
ρ_g    = e^{−δ_g T}           (retention over interval T)
```

### Three temporal decoding regimes

| Regime | δ | ρ | Cortex mapping |
|---|---|---|---|
| **Reset** (short memory) | large | ≈ 0 | Episodic noise · low-weight synapses · prune candidates · packet-only hits |
| **Integrate** (intermediate) | medium | (0,1) | Connect metric graph rollups · prefetch precision · ranker online weights |
| **Retain** (long memory) | small | ≈ 1 | Discovery Cards · canonical (GCMT-promoted) · hierarchical contains · taught packets |

```text
reset  →  integrate  →  retain
```

Same upstream pulse; **qualitatively different** persistence — as when
ρ_slow = ρ_fast^{1/100} turns 10% retention into ~97.7% for a 100× slower
decoder (illustrative identity, not a lab claim on this repo).

### Separation of roles

```text
clock  ≠  memory  ≠  decision
```

| Role | Cortex organ | Must not do |
|---|---|---|
| **Clock / broadcaster** | Thalamus + connect pass + organism pulse | Store all history alone |
| **Memory / filters** | Multi-res graph · HNSW · metric_graph · cards · kernels | Authorize mutation |
| **Decision / commit** | Governor · immune · contract · (host/human) | Be replaced by relevance |

**Principle:**

> Biological systems (and good memory systems) encode temporal meaning by
> projecting a **common signal** through a **spectrum of memory kernels**.
> Each decoder commits when its **own** retained, consequence-normalized
> evidence crosses **its own** boundary — under law that relevance never
> becomes rights.
