# GSI-II.2 — proof-chain closure

September 7, 2026. Product remains `10.0.0a39`. Implementation baseline:
`8e05bd171b2ac5f3c73d9534298be7f6c2c2a753`. Zero provider calls.

This pass hardens the GSI proof chain. It does not establish cumulative empirical
self-improvement and does not authorize a live learning experiment.

## Closed deterministic path

```text
measured opportunity
  -> frozen experiment + utility contract
  -> exact structured intent compilation
  -> attested candidate artifact
  -> evidence-derived constitutional verdict
  -> matched development/withheld disposition
  -> canonical authenticated promotion membrane
  -> exact artifact application
  -> full post-promotion disposition
  -> realized-generation receipt
  -> Store-reconstructed cumulative chain
```

The existing alpha.8 tournament promotion and GSI now share one mutation
membrane in `cortex/autonomous_improvement.py`. Eligibility remains specific to
each caller, while scope, source freshness, isolated canary, exact proposal
application and non-derived authority have one implementation.

## New identities and distinctions

- `cortex-improvement-utility-contract/1.0` binds the metric, direction,
  development and withheld workloads, thresholds and comparison semantics.
- `cortex-gsi-post-promotion-measurement/1.0` binds the evaluated proposal,
  promoted proposal, expected postimages, applied postimages and full frozen
  improvement disposition.
- `cortex-realized-improvement-generation/1.0` requires a non-rolled-back
  promotion, passing post-promotion measurement and evidence-linked source
  transition. A positive unpromoted trial remains `CANDIDATE_GENERATION`.
- Verified bounded reuse is explicitly `EXPERIMENT_EVIDENCE`. It is not active
  memory guidance, admission, policy or authority.
- Failure constraints carry causal class. Only `CANDIDATE_CAUSAL` failures emit
  exclusion predicates.
- A bounded dependency closure hashes target files, direct local Python imports
  and declared dependencies. It is not whole-program proof.

## Constitutional evaluation

GSI no longer fills invariant PASS states directly. `evaluate_gsi_constitution`
reconstructs required states from explicit evidence and the canonical invariant
registry. Missing evidence or missing registered invariants produce `HELD`.

Required gates remain noncompensatory. Performance cannot compensate for
unknown constitution, stale source, failed attestation, evaluator drift,
environment mismatch or authority leakage.

## Promotion conservation

Before mutation, GSI requires the current HEAD, policy hash, environment,
subject preimages and full control surface to match the frozen experiment.
Promotion uses the exact proposal from the independently attested compilation;
it does not reconstruct a new diff from model strings.

After live application, Cortex reruns both frozen workloads and recomputes the
same improvement disposition. Correctness alone is insufficient. A failed
promoted-state disposition triggers rollback.

```text
H(evaluated proposal)
  = H(promoted proposal)
  = H(applied postimages before evaluation)
```

within the declared target surface.

## Cumulative chain semantics

Canonical cumulative inspection accepts generation receipt hashes and resolves
the trial, promotion, post-promotion measurement and utility contract from
Store. It verifies parent receipt linkage and source-state continuity.

Unrelated utility deltas are not additive. Compatible utility contracts permit
a bounded scalar; incompatible contracts preserve a utility vector.

The GSI-II.1 two-target fixture therefore remains mechanical evidence. Its
value and rank repairs are not a single scalar cumulative-utility result.

## Holdout boundary

Deterministic fixtures now bind disjoint candidate and holdout capability sets.
Enforcement remains an interface boundary, not an OS sandbox. Consequently:

`live_provider_holdout_eligible = false`.

A live provider experiment remains HELD until candidate generation cannot read
the heldout definition, receipt or execution capability.

## Claim boundary

Allowed after deterministic controls and exact-head CI:

> Cumulative self-improvement proof-chain mechanics verified in deterministic
> controls.

Not established:

- live cumulative self-improvement;
- improvement-search utility from inherited Cortex history;
- cross-model or general competence gain;
- unrestricted production mutation;
- any authority expansion, consciousness or sentience claim.

`cumulative_self_improvement_established` remains `false`.
