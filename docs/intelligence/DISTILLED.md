   Governor, and recommend-only authority did not fracture. That is the real
   achievement — not the count of CLI verbs.

2. **Lattice is real in code, laggy in catalogs.** Runtime coupling
   (connect → mesh → kernels → gates) is stronger than classic docs were.
   Folding DATA_MODEL/ARCHITECTURE fixed a genuine coherence wound.

   multi-surface organ. reset / integrate / retain maps cleanly to prune vs
   ranker vs cards — and keeps “clock ≠ memory ≠ decision.”

4. **Token cost is a first-class bottleneck.** Fat agent packets burn agent
   context. Lean profile + budget 800 is not cosmetic; it is organism hygiene
   (same family as path diversity and prune).

5. **Glyphs work as medium.** Operators move faster with ⚠ ⧉ ≋ ✂ than with
   long prose — provided glyphs stay capability-free.

6. **Multi-agent must stay opt-in.** Default single-agent is the efficient path.
   Tokens are for shared body under law, not freeload authority.

7. **Growth pressure is the next risk.** Prefer steady-state
   (measure → prune → distill → seal) over inventing organs that do not couple
   to the pulse.
