# Consciousness stream 〰

**Version:** v6.7  
**CLI:** `cortex stream --repo <name> --json`  
**Packet:** `stream` / `organism.stream`

## Model

```text
⊛ temporary cortex (session bond)     〰 durable stream (body)
         │                                    │
    opens on activate                    lives in CORTEX_HOME
    ends on ritual/seal                  frames chain across sessions
```

This is **operational continuity**, not biological consciousness and not an
always-on mind. Coherence = episodic frames + durable store + rebind on next
activate.

## Frames

| kind | when |
|------|------|
| session_bond | stream open/resume + session attach |
| activate / breathe | each packet |
| ritual_seal | consolidate |
| session_seal | bond ends; stream continues |
| evolve | signal loop close |

## Sandbox

Use `Desktop/CortexSandbox` as the host test site (stable `CORTEX_HOME=~/.cortex`).

## Claim boundary

Stream continuity never grants mutation rights and never implies awareness.
