# Phase v8.1.1 — Measurement-First Routing

**Status:** operational routing and telemetry correction  
**Boundary:** recommend-only memory behavior; no host authority and no consciousness claim.

## Purpose

Adaptive routing must not optimize against truncated, stale, or unmatched signals. This phase repairs the measurement chain before changing the field.

## Geometry

- Structural alignment counts every `edges` row by relation. The `Store.edges()` 500-row browsing limit is never used as a graph denominator.
- Neural-to-structural mass is expected to remain in an order-one band because both layers compile from the same repository substrate. Reverse and containment relations explain bounded differences.
- Interconnect control state is derived from one live certificate/manifest observation and reports the certificate hash, epoch, phase, and capture time together.
- Stored intelligence pulses carry their original mesh observation; readers receive age, staleness, and current-mesh agreement explicitly.

## Routing economics

For levels ordered `symbol → file → module`, Fibonacci allocation is `1:2:3`, not `3:2:1`. An exhausted lane first borrows from a coarser envelope, then reclaims unused finer mass. Total use remains bounded by the original context budget.

Visible retrieval results contain at most one chunk per path. Internal context assembly may still use separately bounded chunks when the packet profile permits it.

## Learned policy

- Ranker and spectral utility are measured independently.
- A sealed holdout with no spectral lift moves spectral enrichment into a graph-geometry query lane; it does not delete spectral features.
- Coactivation prefetch uses specificity-normalized association, and ranker output reserves a small novelty term so high-frequency hubs cannot monopolize every route.
- Emergence instructions quote the latest measured gate; coherence alone cannot assert component utility.

## Causal evidence

Connect cadence without a matched counterfactual is deferred rather than written as an inconclusive causal episode. Sealed holdout ablations may record stable receipts for local component utility. These receipts are not live task outcomes or universal causal proof.
