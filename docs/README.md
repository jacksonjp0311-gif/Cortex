## Which document is authoritative?

STATUS owns the current **reviewed epistemic state**; SYSTEM_MAP owns the current
bird's-eye architecture; AGENT_START owns tracked AI orientation. Specialized
references own their domain detail, not the whole system. Research proposes;
experiments record; generated reports index. None grants authority.

[Cortex knowledge map](CORTEX_KNOWLEDGE_MAP.json) classifies roles and links concepts
to code, tests and evidence. [Migration inventory](DOCUMENTATION_MIGRATION.md)
records what was preserved and why old front-door language was reclassified.
