# Coherence Mirror

The mirror is Cortex looking at itself under controlled stress. It does not
grant authority, mutate the host, or claim consciousness. It reports whether
the closed grammar still holds.

```bash
python -m cortex mirror --json
python -m cortex mirror /path/to/repo --name MyMirror --json
python -m cortex contact --json
```

`cortex contact` strikes the full tuning fork: self-mirror + fluency corpus +
expanded foreign host matrix (python, node, docs, go, mixed). Brightness is a
multi-string resonance score (economics, evidence, geometry, fluency, contact,
timing) — not savings alone.

## What it measures

| Signal | Pass condition |
|---|---|
| Bootstrap certificate | `verified` |
| Deferred ARIA bulk | Survives bootstrap **and** generic activation |
| Fluency corpus | Zero false wakes, zero missed wakes |
| Packet surfaces | `aria_materialization` + `constitutional_supervision` present |
| Generic task | ARIA mode `dormant`, zero eligible ARIA nodes |
| ARIA wake | Mode `active`, deferred materializes once |
| Authority | Mutation never self-granted |

`glow: true` means break_count is zero. `glow_intensity` rises with measured
bootstrap savings when the economics still hold.

## Break that taught the system

**Symptom:** After bootstrap, index reported 284 deferred files, but the store
immediately showed 0 deferred / full ARIA index.

**Cause:** Certificate retrieval probes used README headings such as
`Native ARIA semantic language`. `query()` auto-materialized the substrate on
any ARIA cue — including probes — during `verify_repository`.

**Fix:** Substrate materialization is explicit and intentional:

- activation / `build_context` / CLI `query` may materialize;
- verify probes and internal hybrid calls do **not**.

That restored deferred-tier economics (~4.7s bootstrap on the Cortex tree with
~66% estimated work-proxy savings) while keeping wake materialization correct.

## Claim boundary

The mirror is local coherence telemetry. A glowing mirror means the declared
invariants held for this stress run. It does not prove universal readiness,
biological fidelity, or permission to mutate repositories.
